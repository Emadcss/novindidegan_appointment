# تفاوت «مستند پروژه» با کد فعلی

`project document.txt` مستند تصمیم‌های اولیه است و از نظر تاریخی ارزشمند می‌ماند. در جدول زیر جاهایی که کد از آن جلو افتاده یا فرق دارد آمده است. (بخش‌ها با شماره‌ی مستند ارجاع داده شده‌اند.)

| بخش | مستند اولیه | کد فعلی |
|---|---|---|
| §3–§5 هویت بصری | UI شیشه‌ای تیره، پس‌زمینه‌ی متحرک پزشکی | تم روشن پرکنتراست، پس‌زمینه‌ی ثابت، لوگو و ساعت در گوشه‌ها (`docs/ui-ux`) |
| §3 فونت | چند فونت | میخک (۳ وزن) برای رابط و آقاسم برای لوگوتایپ |
| §6 ساعت | ساعت زنده | ساعت با ثانیه‌شمار؛ هشدار در صورت قطع ارتباط سرور |
| §15 شماره نوبت | هر **تخصص** صف مستقل | **تصمیم نهایی: هر پزشک صف مستقل دارد** (کلید: تخصص، پزشک، روز). §15 باید اصلاح شود |
| §18 مدل Appointment | بدون `patientId`، `appointmentTime`، `status` | علاوه بر آن‌ها `requestId` (idempotency) هم دارد |
| §23 نوبت قبلی | `PreviousAppointmentLookup` بررسی می‌کند (بدون API) | `POST /appointments/lookup`؛ همه‌ی نوبت‌های فعال امروز؛ اگر چندتا بود صفحه‌ی انتخاب (`previous-select`) |
| (جدید) چند نوبت در روز | — | چند پزشک/تخصص مجاز؛ همان پزشک `DUPLICATE`؛ سقف ۳ نوبت فعال در روز `LIMIT` |
| §25 سؤال جراحی | اختیاری بر اساس پزشک | سرور اجباری بودن را اعمال می‌کند و فقط برای همان پزشکان ذخیره می‌کند؛ در جریان «نوبت قبلی» پرسیده نمی‌شود |
| §29 Navigation | «بازگشت» و «لغو عملیات» | «بازگشت» و «انصراف»، جای ثابت پایین صفحه |
| §30 Timeout | ۹۰ ثانیه بی‌فعالیتی ← ریست | هشدار در ثانیه‌ی ۶۰ (با «ادامه می‌دهم» و «انصراف و پاک کردن اطلاعات») و ریست در ۹۰؛ صفحه‌ی نوبت ۵ ثانیه بعد بسته می‌شود |
| §31 State | step، flow، specialty، … | علاوه بر آن‌ها `sessionRef` و `requestIdRef` برای ایمنی |
| §32 Validation در Backend | «باید دوباره انجام شود» | انجام شد (`lib/kiosk/identity.ts`) |
| §39 مرحله‌ی ۱ (UI) | چند مورد باز | Timeline، کارت‌ها، Loading و موفقیت انجام شد؛ «در حال چاپ» و «خطای چاپ» منتظر چاپگر؛ تست لمس منتظر سخت‌افزار |
| §39 مرحله‌ی ۳ (Backend) | همه باز | APIهای تخصص، پزشک، lookup، ثبت، اعتبارسنجی و مدیریت خطا روی داده‌ی حافظه انجام شد؛ اتمیک بودن شماره و لاگ منتظر دیتابیس |
| §39 مرحله‌ی ۵ پیام قبض | «پس از دریافت قبض به پذیرش مراجعه فرمایید» | روی **قبض چاپی** همین بماند؛ صفحه‌ی نمایشگر فعلاً می‌گوید «برای تکمیل پذیرش، به باجه‌ی پذیرش مراجعه کنید» تا قول چاپ ندهد |
